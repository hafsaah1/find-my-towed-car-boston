Boston Towed Cars

Every car the City of Boston has on record as towed in the last 7 days. Data is scraped from the city's lookup tool, which only exposes partial-plate search — so coverage depends on the prefix scan completing.

About the map pins. The Boston source has no per-car coordinates, so each pin sits near the towing company's yard with deterministic jitter to suggest the neighborhood it services. BTD city-wide tows are scattered across Boston by plate hash. Pin colors are per make — same color = same brand.
